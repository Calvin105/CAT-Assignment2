## Goals & Intent
The primary goal is to apply principles of GUI design and modern web development (React.js and Node.js) by developing a professional, original, and responsive company homepage. The intent is to simulate a start-up environment where the team forms a company and defines their roles.

## Technical Stack
**Frontend:** React.js(mandatory), Tailwind CSS (for convenience)

**Runtime:** Node.js (mandatory)

**Icon Library:** [LucideIcon](https://lucide.dev/icons/) SVG or JSX only

**Content Creation Tools:** Any graphic/video editing tools

## Tips on Originality & Development Improvements
### ReactBits
You may use [ReactBits components](https://reactbits.dev/get-started/index) for inspirations. Furthermore, explore some of the components in ReactBits because some components only requires React.js and no external libraries required. For example, the [electric-border component](https://reactbits.dev/animations/electric-border) only requires React.js and no external libraries required. However, you are not allowed to use ReactBits components in your final product.

### Tailwind CSS
The use of Tailwind CSS is actually not permitted. However, we may use Tailwind CSS for our own convenience to create the UI. Later on, we replace the Tailwind CSS with our own CSS.

### How to Design?
> **Note:** Ensure consistent design colour across the entire website.

1. The use of AI to vibe code or generate UI will be generic. 

2. May use UI generation AI to generate UI like Figma or [UIzard](https://uizard.io).

3. Gather tons of inspirations from Pinterest, Behance and Dribble onto Figma to create a moodboard.

4. Take references from companies like [Jabil](https://jabil.com)

5. Trust your instincts and create a unique design.
